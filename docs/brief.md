# PharmacyWarehouse — خلاصه‌ی پروژه

طراحی کامل: `docs\spec.md`. این فایل فقط خلاصه، نقشه‌ی راه و وضعیت جاری است.

## ۱. هدف
مدیریت انبار یک داروخانه‌ی خصوصی: قلم، بچ و انقضا، محل‌های درختی، ورود جنس، برداشت با پیشنهاد FEFO، بررسی برداشت، انبارگردانی و تاریخچه‌ی کامل. کاربران: انباردار، کارکنان داروخانه، مدیر داروخانه.

## ۲. تصمیم‌های کلیدی (۲۰۲۶-۱۱-۰۴)
- [تصمیم] زیرساخت از Emu: Api + Blazor WebAssembly + Domain، SQLite، ورود و مجوز و تاریخچه مثل Emu.
- [تصمیم] موجودی فقط با `StockMovement`؛ `OnHand` در همان تراکنش؛ مقدارها صحیح.
- [تصمیم] نقش‌ها: Admin، کارکنان، انباردار، مدیر داروخانه.
- [تصمیم] نشست ۳۰ روز؛ غیرفعال کردن کاربر نشست‌ها را فوراً باطل می‌کند.
- [تصمیم] اعلان پشتیبان قدیمی بعد از ۱ روز؛ پشتیبان شبانه‌ی خودکار روی سرور، علاوه بر دانلود دستی روزانه‌ی انباردار روی لپ‌تاپ خودش.
- [تصمیم] سرور: کامپیوتر معمولی با ویندوز ۱۱ (نه Server، نه VM)؛ Sleep و Hibernate خاموش، Active hours تنظیم شود، UPS.
- [تصمیم] گوشی‌ها بیشتر iPhone هستند: گواهی self-signed باید به‌صورت profile نصب شود و در Certificate Trust Settings به‌طور کامل مورد اعتماد شود.
- [تصمیم] پورت‌ها: Api روی 7500، Client روی 7600.
- [تصمیم] هیچ داده‌ی واقعی (فایل Excel داروخانه، نام کارکنان، بچ‌نامبرها) وارد Git نمی‌شود.
